## Ejecutar en desarrollo
1. Clonar el repositorio
2. Ejecutar
```bash
npm install
```
3. Instalar NestJS CLI
```
npm install -g @nestjs/cli
npm run start:dev
```
4. Levantar la base de datos
```
docker-compose up -d
```
5. Iniciar la aplicación
```
npm run start:dev
```
